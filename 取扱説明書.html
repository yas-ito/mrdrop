このツールについて

Mr.Drop は、iPhone から、同じ Wi-Fi につながっている PC へファイルを送る道具です。 Windows には AirDrop が無いので、その代わりになるものとして作りました。

  • インターネットを通りません。端末どうしが直接やりとりします。写真がどこかのサーバーに残ることはありません
  • 元のまま届きます。HEIC が JPEG に変換されたり、動画が小さくされたりしません
  • アプリを入れなくても使えます。iPhone の Safari で開くだけです
  • PC → iPhone もできます。PC の「送信箱」に入れたものを、iPhone から受け取れます
追加のソフトは何も入りません。この道具は外部の部品（npm パッケージ）を1つも使っていないので、 入るのは server フォルダの中の数個のファイルだけです。

使う前に — Node.js を入れる

この道具は Node.js という無料の実行環境の上で動きます。PC に入っていなければ、先に入れてください（1回だけです）。

入れ方（どちらでも構いません）

  • 公式サイトから：https://nodejs.org/ja を開き、LTS と書かれた方をダウンロードして実行します。設定は変えず「次へ」で進めて構いません
  • コマンドから（Windows 11）：スタートを右クリック →「ターミナル」を開いて、次を貼り付けます 
    winget install OpenJS.NodeJS.LTS
入れたあとは、開いていた黒い画面を一度閉じてから「はじめる.bat」を押してください。 閉じないと、入れたばかりの Node.js を見つけられないことがあります。

送る・受け取る

iPhone → PC（送る）

画面の「写真・動画を選ぶ」または「ファイルを選ぶ」を押して、送りたいものを選びます。

⚠ 送信ボタンはありません

選んだ瞬間に送り始めます。「送信」ボタンを探す必要はありません。 棒グラフが伸びて「送りました」に変われば完了です。何度も選び直すと、同じ写真が何枚も届きます。

届いたものは PC の受信箱（初期設定ではデスクトップの「受信箱」フォルダ）に入ります。

PC → iPhone（受け取る）

PC の送信箱フォルダに入れたファイルが、iPhone の画面の下の方に一覧で出ます。 「受け取る」を押すと iPhone に落ちます。

大きい動画を送るとき

  • 数GB の動画でも送れます。速さは Wi-Fi 次第です（有線の PC 相手なら、実測で毎秒 60〜80MB 出ています）
  • 途中で切れたファイルは受信箱に出しません。中途半端なファイルが紛れ込まないようにしてあります。切れたら、もう一度送ってください
  • iPhone の画面は、送っている間つけたままにしてください

安全の話（読んでください）

⚠ 同じ Wi-Fi にいる人は、誰でも使えます

初期設定では、同じネットワークの中にいる人なら誰でもあなたの PC へファイルを送れ、 送信箱の中身を見て受け取れます。家の Wi-Fi なら問題になりませんが、 職場・学校・宿・カフェなど、知らない人が同じ Wi-Fi にいる場所では使わないでください。

  • インターネット側からは使えません。同じネットワークの中からしか受け付けない作りになっています
  • ファイアウォールは「プライベート ネットワーク」だけに開けてください（上の手順2）
  • 受信箱と送信箱の外には、絶対に書き込みません。ファイル名に ..\ のような細工がされていても、名前だけを取り出して受信箱に入れます

合言葉をつける

どうしても人の多いネットワークで使うなら、合言葉を設定してください。

  1. 一度「はじめる.bat」を動かすと、隣に config.json ができます
  2. メモ帳で開いて "token": "" を "token": "すきな合言葉" に書き換えます
  3. 黒い画面を閉じて、もう一度「はじめる.bat」を押します
  4. iPhone からは http://…:48630/?t=すきな合言葉 で開きます

置き場所と設定

「はじめる.bat」の隣にできる config.json を書き換えると、置き場所や番号を変えられます。

項目意味
port使う番号。初期値は 48630。他のソフトとぶつかったときだけ変えてください
inboxiPhone から届いたものが入るフォルダ
outboxここに置いたものを iPhone から受け取れます
nameiPhone に見える名前。空なら PC 名になります
token合言葉。空なら合言葉なしです
✓ 使い道のひとつ

inbox を動画編集の素材フォルダにしておくと、iPhone で撮った素材が、 そのまま編集用のフォルダに落ちてきます。取り込みの手間がまるごと無くなります。

ずっと使えるようにする（任意）

毎回「はじめる.bat」を押すのが面倒なら、Windows にログインしたら勝手に動くようにできます。 黒い画面も出なくなります。

  1. scripts フォルダを開く
  2. install-windows.ps1 を右クリック →「PowerShell で実行」
    うまくいかないときは、スタートを右クリック →「ターミナル（管理者）」を開き、 cd のあとに scripts フォルダをドラッグしてから .\install-windows.ps1 と打ちます。

ファイアウォールを開け、自動で立ち上がるように登録します。管理者の権限が要ります。

やめたいとき.\install-windows.ps1 -Uninstall（受信箱の中身はそのままです）
今どうなっているか.\install-windows.ps1 -Status

よくある質問

iPhone の Safari で .local の住所が開けません
黒い画面に一緒に出ている http://192.168.… の方を打ってください。こちらは必ず開きます。 .local は Wi-Fi 機器によって通らないことがあります。
どちらの住所でも開けません
まず iPhone と PC が同じ Wi-Fi かを確かめてください（PC が有線でも、同じルーターなら大丈夫です）。 次に、Windows のファイアウォールで「プライベート ネットワーク」を許可したかを確かめてください。 scripts\install-windows.ps1 を実行すると、そこも含めて整えられます。
「WindowsによってPCが保護されました」と出ました
インターネットから落としたファイルに出る警告です。「詳細情報」→「実行」で進めます。 気になるときは、ZIP を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェックを入れてから展開してください。
黒い画面を閉じてしまいました
もう一度「はじめる.bat」を押せば戻ります。送っている途中で閉じた場合、そのファイルは届いていません （中途半端なファイルは残らないようにしてあります）。
同じ名前のファイルを送ったら、上書きされますか
されません。写真.jpg の次は 写真 (2).jpg になります。
iPhone のアプリはありますか
ソースはありますが、配布はしていません（App Store に出していないため、 入れるには Mac と Xcode が要ります）。Safari から使う分には、アプリと同じことができます。 共有ボタン →「ホーム画面に追加」をしておくと、見た目もアプリとほぼ同じになります。
Android でも使えますか
同じ Wi-Fi にいれば、Chrome で同じ住所を開くだけで使えます。iPhone 専用ではありません。
Mac でも動きますか
動きます。ただしこの ZIP は Windows 用で、Mac 用の起動役は入っていません。 Mac で使うときは配布元から一式を取得し、bash scripts/install-mac.sh を実行してください （受信箱は ~/Downloads/受信箱 になります）。

動作環境

Windows 10 / 11 Node.js 18 以降 iPhone（Safari）/ Android（Chrome） 同じ Wi-Fi（LAN）
すべての環境での動作を保証するものではありません。Wi-Fi 機器の設定によっては、 同じネットワークにいる機器どうしの通信が禁止されている場合があり（プライバシーセパレータ等）、 そのときはこの道具は使えません。
