このツールについて

Mr.Drop は、iPhone から、同じ Wi-Fi につながっている PC へファイルを送る道具です。 Windows のパソコンには、iPhone から無線で受け取るしくみが標準では入っていません。 その代わりになるものとして作りました。

  • 写真がインターネットに流出することはありません。iPhone とパソコンが直接やりとりします。どこかのサーバーに残ることもありません
  • 初期設定では、写真は JPEG で届きます。Windows でそのまま開けるようにするためです。動画は MP4 に詰め替えるだけで、画質は変わりません。撮ったままの形式（HEIC・MOV）が良いときは、iPhone アプリの「送る形式」を切ってください
  • 撮った日がそのまま残ります。パソコンに届いたファイルの「更新日時」は、写真・動画なら撮影日時、書類や PDF なら元のファイルの日付になります。届いた順に並べたいときは「作成日時」で並べ替えてください
  • iPhone アプリが App Store で無料です。写真アプリの共有ボタンから、そのまま送れます
  • PC → iPhone もできます。PC の「送信箱」に入れたものを、iPhone アプリの「受け取る」から受け取れます（アプリ 1.1.0 以降）。アプリを入れていないときは iPhone のブラウザ（Safari / Chrome）からでも受け取れます
追加のソフトは何も入りません。この道具は外部の部品（npm パッケージ）を1つも使っていないので、 入るのは server フォルダの中の数個のファイルだけです。

使う前に — Node.js を入れる

この道具は Node.js という無料の実行環境の上で動きます。PC に入っていなければ、先に入れてください（1回だけです）。

入れ方（どちらでも構いません）

  • 公式サイトから：https://nodejs.org/ja を開き、LTS と書かれた方をダウンロードして実行します。設定は変えず「次へ」で進めて構いません
  • コマンドから（Windows 11）：スタートを右クリック →「ターミナル」を開いて、次を貼り付けます 
    winget install OpenJS.NodeJS.LTS
入れたあとは、開いていた黒い画面を一度閉じてから「はじめる.bat」を押してください。 閉じないと、入れたばかりの Node.js を見つけられないことがあります。

送る・受け取る

iPhone → PC（送る）

画面の「写真・動画を選ぶ」または「ファイルを選ぶ」を押して、送りたいものを選びます。

⚠ 送信ボタンはありません

選んだ瞬間に送り始めます。「送信」ボタンを探す必要はありません。 棒グラフが伸びて「送りました」に変われば完了です。何度も選び直すと、同じ写真が何枚も届きます。

届いたものは PC の受信先に入ります。初期設定は C:\Users\あなた\Downloads、 つまりいつもの「ダウンロード」フォルダそのものです。専用のフォルダは作りません。

PC → iPhone（受け取る）

デスクトップの「Mr.Drop送信箱」フォルダに入れたファイルを、iPhone から受け取れます。

デスクトップに見当たらないときは、タスクバーのアイコンを右クリック → 「送信箱を開く」を押してください。そこが送信箱です。
OneDrive で「デスクトップ」をバックアップしていると、デスクトップそのものが C:\Users\あなた\OneDrive\デスクトップ に移っていることがあり、送信箱もそちらにできます。
⚠ 場所を変えるときは、メニューから

エクスプローラで送信箱ごと別の場所へ移すと、iPhone から中身が見えなくなります （空の送信箱に見えます）。Mr.Drop は元の場所を見にいくためです。

送信箱は好きな場所にできます。タスクバーのアイコンを右クリック → 「送信箱を変える...」でフォルダを選んでください。 いまの送信箱に中身があれば、移すかどうかを聞かれます。

デスクトップから開きたいだけなら、右クリック →「その他のオプションを表示」→「送る」 →「デスクトップ (ショートカットを作成)」でショートカットを置く手もあります。

⚠ こちらは iPhone から取りに行く作りです

送信箱に入れても、iPhone にもパソコンにも通知は出ません。 iPhone から見に行ったときに、一覧に出ます。 （アプリが閉じているあいだ、iOS は Wi-Fi を見張らせてくれないためです）

  ① iPhone アプリで受け取る（おすすめ）

  1. iPhone で Mr.Drop アプリを開き、下の「受け取る」を押します
  2. 送信箱の中身が一覧で出ます。「すべて受け取る」を押します
  3. 写真と動画は「写真」アプリへ、それ以外は「ファイル」アプリの Mr.Drop › 受信 へ入ります
受け取ったものには印が付くので、同じものを二度受け取ることはありません。 受け取っても送信箱のファイルは消えません（置いた人の物を勝手に消さないためです）。
※ この受け取り機能は iPhone アプリ 1.1.0 以降です。App Store で更新してください。

  ② ブラウザで受け取る（アプリを入れていないとき）

  1. iPhone のブラウザで http://＜PC名＞.local:48630 を開きます。 この住所は、タスクバーの Mr.Drop のアイコンにマウスを乗せると出ます
  2. 初回は「ローカルネットワーク上のデバイスへのアクセスを許可しますか」と聞かれるので「許可」を押します。 これはアプリごとに聞かれます。Mr.Drop アプリで許可済みでも、Safari や Chrome では改めて聞かれます
  3. 画面を下へスクロールすると「この PC から受け取る」の欄に、送信箱の中身が一覧で出ます
  4. 「受け取る」を押すと iPhone に落ちます。落ちる場所はブラウザによって違います
    Safari … 「ファイル」アプリ →「ダウンロード」
    Chrome … 「ファイル」アプリ →「このiPhone内」→「Chrome」
    写真や動画は、そこから共有ボタン →「画像を保存」「ビデオを保存」で写真アプリに入ります
毎回住所を打つ必要はありません。共有ボタン（Safari は画面の下、Chrome は右上）から 「ホーム画面に追加」しておくと、次からはアイコンを押すだけで全画面で開きます。ふつうのアプリとほとんど同じ使い勝手になります。
登録するときは、なるべく ＜PC名＞.local の方をお使いください。192.168… の番号は、 パソコンやルーターを再起動すると変わることがあり、そうなるとアイコンから開けなくなります。

大きい動画を送るとき

  • 数GB の動画でも送れます。速さは Wi-Fi 次第です（有線の PC 相手なら、実測で毎秒 60〜80MB 出ています）
  • 途中で切れたファイルは受信先に出しません。中途半端なファイルが紛れ込まないようにしてあります。切れたら、もう一度送ってください
  • iPhone の画面は、送っている間つけたままにしてください

安全の話（読んでください）

⚠ 同じ Wi-Fi にいる人は、誰でも使えます

初期設定では、同じネットワークの中にいる人なら誰でもあなたの PC へファイルを送れ、 送信箱の中身を見て受け取れます。家の Wi-Fi なら問題になりませんが、 職場・学校・宿・カフェなど、知らない人が同じ Wi-Fi にいる場所では使わないでください。

  • インターネット側からは使えません。同じネットワークの中からしか受け付けない作りになっています
  • ファイアウォールは「プライベート ネットワーク」だけに開けてください（上の手順2）
  • 受信先と送信箱の外には、絶対に書き込みません。ファイル名に ..\ のような細工がされていても、名前だけを取り出して受信先に入れます

合言葉をつける

どうしても人の多いネットワークで使うなら、合言葉を設定してください。

  1. 一度動かすと %LOCALAPPDATA%\MrDrop\config.json ができます （エクスプローラの住所欄にそのまま貼れます）
  2. メモ帳で開いて "token": "" を "token": "すきな合言葉" に書き換えます
  3. タスクバーのアイコンを右クリック →「受信先を変える...」→「キャンセル」で、設定が読み直されます
    または、パソコンを再起動しても読み直されます
  4. iPhone からは http://…:48630/?t=すきな合言葉 で開きます

受信先を変える

届いたものが入るフォルダは、後から自由に変えられます。

1
タスクバーのアイコンを右クリック →「受信先を変える...」
⚙️ 受信先を変える...

フォルダを選ぶ画面が出ます。選んで「OK」を押すだけです。 常駐させている場合は、そのまま新しい受信先で動き出します。

✓ いちばんおすすめの使い方

受信先を動画編集の素材フォルダにしておくと、iPhone で撮った素材が、 そのまま編集用のフォルダに落ちてきます。取り込みの手間がまるごと無くなります。

アイコンを右クリック →「受信先を開く」で、いまの受信先をそのまま開けます （アイコンをダブルクリックしても開きます）。 同じところの「送信箱を開く」で、iPhone へ渡す物を置く送信箱も開けます。

送信箱も、好きな場所にできます。「送信箱を変える...」でフォルダを選びます。 いまの送信箱に中身があるときは、「新しい送信箱へ移しますか？」と聞かれます （「いいえ」を選べば、今の場所にそのまま残ります。移すときも、同じ名前が先にあれば 上書きせずに前の場所へ残します）。

⚠ デスクトップやビデオを「丸ごと」は選べません

デスクトップ・ドキュメント・ピクチャ・ビデオ・ミュージック・ダウンロード、 それにユーザーフォルダやドライブそのものは、送信箱にできないようにしてあります。 送信箱の中身は同じ Wi-Fi から一覧できるので、そこに置いてある物が 全部見えてしまうためです。

そういう場所を使いたいときは、その中に新しいフォルダを作って、そちらを選んでください （フォルダを選ぶ画面の「新しいフォルダーの作成」で作れます）。 受信先と同じフォルダも、同じ理由で選べません。

展開したフォルダをまだ持っているなら、その中の 受信先を変える.bat / 受信先を開く.bat でも同じことができます。 どちらを押しても、見ている設定は同じ1つです。

こまかい設定（触らなくても使えます）

%LOCALAPPDATA%\MrDrop\config.json を書き換えると、番号や名前も変えられます。 受信先を変えるだけなら、上の「受信先を変える」で足ります。

項目意味

やめたいとき・1回だけ動かしたいとき

Mr.Drop はパソコンを起動すると勝手に動きます。ふだんは何もしなくて構いません。

アンインストール（この PC から外す）

タスクバーのアイコンを右クリック →「Mr.Drop をアンインストール」を選んでください。 スタートメニューの Mr.Drop > Mr.Drop をアンインストール でも、 展開したフォルダの アンインストール.bat でも同じです。

Windows が「許可しますか」と聞いてきたら「はい」を押してください。これで次の全部が外れます。

  • 自動起動（パソコンを起動しても、もう出ません）
  • タスクバーの常駐アイコン
  • ファイアウォールに開けた穴
  • スタートメニューの Mr.Drop
  • 入れたプログラムと設定と記録（%LOCALAPPDATA%\MrDrop）
✓ 届いたファイルは消えません

受信先と送信箱の中身にはいっさい触りません。Mr.Drop で受け取った写真や動画は、 そのまま残ります。また使いたくなったら、ZIP を展開して「はじめる.bat」を押すだけです。

新しい版に入れ替えるとき

入れ直す必要はありません。上書きするだけです。 受信先・送信箱・この PC の名前・合言葉といった設定は、そのまま引き継がれます。

  1. BOOTH の購入履歴から、新しい ZIP をダウンロードします
  2. ZIP を右クリック→「すべて展開」（前と同じく、中身だけ取り出すと動きません）
  3. 出てきたフォルダの「はじめる.bat」をダブルクリックします
  4. 動いていた前の版は自動で止まり、新しい版に入れ替わって、また常駐します
  5. 済んだら、ダウンロードした ZIP と展開したフォルダは消して構いません
古い版を先に「アンインストール」しないでください。 設定まで消えてしまいます。上書きで入れ替わるようにしてあります。

iPhone アプリの更新

iPhone アプリは App Store から更新します。

  1. iPhone で App Store を開きます
  2. 右上の自分のアイコンを押します
  3. 下へスクロールすると「利用可能なアップデート」に Mr.Drop が出るので、 右の「アップデート」を押します
  4. 出てこないときは、すでに最新です
iPhone の「設定 → App Store → Appのアップデート」を入にしておくと、 次からは何もしなくても新しくなります。

よくある質問

iPhone の Safari で .local の住所が開けません
黒い画面に一緒に出ている http://192.168.… の方を打ってください。こちらは必ず開きます。 .local は Wi-Fi 機器によって通らないことがあります。
どちらの住所でも開けません
まず iPhone と PC が同じ Wi-Fi かを確かめてください（PC が有線でも、同じルーターなら大丈夫です）。 次に、Windows のファイアウォールで「プライベート ネットワーク」を許可したかを確かめてください。 scripts\install-windows.ps1 を実行すると、そこも含めて整えられます。
「WindowsによってPCが保護されました」と出ました
インターネットからダウンロードしたファイルに出る警告です。「詳細情報」→「実行」で進めます。 気になるときは、ZIP を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェックを入れてから展開してください。
動いているか分かりません
タスクバーの右下を見てください。Mr.Drop のアイコンが出ていれば動いています。 右クリックすると「● 動いています」か「○ 止まっています」も出ます。 アイコンが見当たらないときは、タスクバーの ∧ の中に隠れていないか確かめてください。 それでも無ければ スタートメニュー > Mr.Drop から出し直せます。 送っている途中でパソコンを切った場合、そのファイルは届いていません （中途半端なファイルは残らないようにしてあります）。
同じ名前のファイルを送ったら、上書きされますか
されません。写真.jpg の次は 写真 (2).jpg になります。
iPhone のアプリはありますか
App Store で無料で公開しています（「Mr.Drop」で検索）。 この道具は、アプリを入れたときが本来の形です。写真アプリの共有ボタンからそのまま送れて、 送り先の PC も自動で見つけます。共有ボタンから送れば、アプリを閉じても転送は続きます。
アプリを入れられない iPhone や Android のために、ブラウザだけで送れる画面も用意してあります （Safari で住所を開くだけ。共有ボタン →「ホーム画面に追加」で、次から1タップで開けます）。
Android でも使えますか
同じ Wi-Fi にいれば、Chrome で同じ住所を開くだけで使えます。iPhone 専用ではありません。
Mac でも動きますか
動きます。ただしこの ZIP は Windows 用で、Mac 用の起動役は入っていません。 Mac で使うときは配布元から一式を取得し、bash scripts/install-mac.sh を実行してください （受信先は ~/Downloads＝ダウンロードフォルダそのものになります）。

すべての環境での動作を保証するものではありません。Wi-Fi 機器の設定によっては、 同じネットワークにいる機器どうしの通信が禁止されている場合があり（プライバシーセパレータ等）、 そのときはこの道具は使えません。

更新履歴

v1.0.6

  • 「Mr.Drop送信箱」がデスクトップに出てこないことがあったのを直しました。 OneDrive で「デスクトップ」をバックアップしていると、デスクトップの場所そのものが 移っているためでした。置き場所を決め打ちせず、OS に聞くようにしました。 これまでお使いの方は、更新すると送信箱が中身ごと引っ越します（何もしなくて構いません）
  • タスクバーのアイコンに「送信箱を開く」「送信箱を変える...」を足しました。 送信箱を好きな場所にできます（いまの中身を移すかどうかは、そのつど聞きます。 デスクトップやビデオなどを「丸ごと」は選べません）
  • タスクバーのアイコンのメニューに、入っているバージョンを出すようにしました
  • 「保存先」という呼び方を「受信先」に変えました。「送信箱」と対になって、 どちらがどちらか分かりやすくなります（受信先を変える.bat・ 受信先を開く.bat も名前が変わりました）
