iPhone から、同じ Wi-Fi の PC へ。写真も動画も、そのまま。
Windows / インターネットを通りません
まず、これだけ
  1. ZIP を右クリック →「すべて展開」（中身だけ取り出すと動きません）
  2. はじめる.bat をダブルクリック
  3. iPhone に Mr.Drop アプリを入れる（App Store で無料）
  4. 写真アプリの共有ボタンから「Mr.Drop」を選ぶ。それだけで PC へ届きます

このツールについて

Mr.Drop は、iPhone から、同じ Wi-Fi につながっている PC へファイルを送る道具です。 Windows のパソコンには、iPhone から無線で受け取るしくみが標準では入っていません。 その代わりになるものとして作りました。

  • インターネットを通りません。端末どうしが直接やりとりします。写真がどこかのサーバーに残ることはありません
  • 元のまま届きます。HEIC が JPEG に変換されたり、動画が小さくされたりしません
  • iPhone アプリが App Store で無料です。写真アプリの共有ボタンから、そのまま送れます
  • PC → iPhone もできます。PC の「送信箱」に入れたものを、iPhone から受け取れます
追加のソフトは何も入りません。この道具は外部の部品（npm パッケージ）を1つも使っていないので、 入るのは server フォルダの中の数個のファイルだけです。

使う前に — Node.js を入れる

この道具は Node.js という無料の実行環境の上で動きます。PC に入っていなければ、先に入れてください（1回だけです）。

入れ方（どちらでも構いません）

  • 公式サイトから：https://nodejs.org/ja を開き、LTS と書かれた方をダウンロードして実行します。設定は変えず「次へ」で進めて構いません
  • コマンドから（Windows 11）：スタートを右クリック →「ターミナル」を開いて、次を貼り付けます 
    winget install OpenJS.NodeJS.LTS
入れたあとは、開いていた黒い画面を一度閉じてから「はじめる.bat」を押してください。 閉じないと、入れたばかりの Node.js を見つけられないことがあります。

はじめる.bat をダブルクリック
⚙️ はじめる.bat

黒い画面が出て、こう表示されます。この画面は閉じないでください。 閉じると受け取れなくなります（送っている間だけで構いません）。

    http://my-pc.local:48630
    http://192.168.1.20:48630      （イーサネット）
2
Windows が「アクセスを許可しますか」と聞いてきたら

「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押してください。 ここで断ると、iPhone から PC が見えません。
「パブリック ネットワーク」にはチェックを入れないでください（カフェなどの Wi-Fi で開いてしまわないためです）。

3
iPhone に Mr.Drop アプリを入れる（App Store で無料）

App Store で「Mr.Drop」を検索して入れてください。送り先の PC は自動で見つかります。 住所を打つ必要はありません。あとは写真アプリの共有ボタンから「Mr.Drop」を選ぶだけです。

初めて使うとき、iPhone が「ローカルネットワーク上のデバイスへのアクセスを許可しますか」と聞いてきます。 「許可」を押してください。断ると、同じ Wi-Fi にいても PC を見つけられません （あとから 設定 › プライバシーとセキュリティ › ローカルネットワーク で直せます）。

アプリを入れられないときは — iPhone の Safari で http://＜PC名＞.local:48630 を開いても送れます。開けないときは、黒い画面に出ている http://192.168.… の方を打ってください。共有ボタン →「ホーム画面に追加」 しておくと、次から1タップで開けます。iPhone と PC が同じ Wi-Fi につながっている必要があります。

送る・受け取る

iPhone → PC（送る）

画面の「写真・動画を選ぶ」または「ファイルを選ぶ」を押して、送りたいものを選びます。

⚠ 送信ボタンはありません

選んだ瞬間に送り始めます。「送信」ボタンを探す必要はありません。 棒グラフが伸びて「送りました」に変われば完了です。何度も選び直すと、同じ写真が何枚も届きます。

届いたものは PC の保存先（初期設定ではデスクトップの「保存先」フォルダ）に入ります。

PC → iPhone（受け取る）

PC の送信箱フォルダに入れたファイルが、iPhone の画面の下の方に一覧で出ます。 「受け取る」を押すと iPhone に落ちます。

大きい動画を送るとき

  • 数GB の動画でも送れます。速さは Wi-Fi 次第です（有線の PC 相手なら、実測で毎秒 60〜80MB 出ています）
  • 途中で切れたファイルは保存先に出しません。中途半端なファイルが紛れ込まないようにしてあります。切れたら、もう一度送ってください
  • iPhone の画面は、送っている間つけたままにしてください

安全の話（読んでください）

⚠ 同じ Wi-Fi にいる人は、誰でも使えます

初期設定では、同じネットワークの中にいる人なら誰でもあなたの PC へファイルを送れ、 送信箱の中身を見て受け取れます。家の Wi-Fi なら問題になりませんが、 職場・学校・宿・カフェなど、知らない人が同じ Wi-Fi にいる場所では使わないでください。

  • インターネット側からは使えません。同じネットワークの中からしか受け付けない作りになっています
  • ファイアウォールは「プライベート ネットワーク」だけに開けてください（上の手順2）
  • 保存先と送信箱の外には、絶対に書き込みません。ファイル名に ..\ のような細工がされていても、名前だけを取り出して保存先に入れます

合言葉をつける

どうしても人の多いネットワークで使うなら、合言葉を設定してください。

  1. 一度「はじめる.bat」を動かすと、隣に config.json ができます
  2. メモ帳で開いて "token": "" を "token": "すきな合言葉" に書き換えます
  3. 黒い画面を閉じて、もう一度「はじめる.bat」を押します
  4. iPhone からは http://…:48630/?t=すきな合言葉 で開きます

保存先を変える

届いたものが入るフォルダは、後から自由に変えられます。

1
保存先を変える.bat をダブルクリック
⚙️ 保存先を変える.bat

フォルダを選ぶ画面が出ます。選んで「OK」を押すだけです。 常駐させている場合は、そのまま新しい保存先で動き出します。

✓ いちばんおすすめの使い方

保存先を動画編集の素材フォルダにしておくと、iPhone で撮った素材が、 そのまま編集用のフォルダに落ちてきます。取り込みの手間がまるごと無くなります。

保存先を開く.bat を押すと、いまの保存先をそのまま開けます。

こまかい設定（触らなくても使えます）

「はじめる.bat」の隣にできる config.json を書き換えると、番号や名前も変えられます。 保存先を変えるだけなら、上の「保存先を変える.bat」で足ります。

項目意味
port使う番号。初期値は 48630。他のソフトとぶつかったときだけ変えてください
inboxiPhone から届いたものが入るフォルダ
outboxここに置いたものを iPhone から受け取れます
nameiPhone に見える名前。空なら PC 名になります
token合言葉。空なら合言葉なしです

黒い画面を出さないようにする（おすすめ）

毎回「はじめる.bat」を押して、黒い画面を開いたままにするのが面倒な方へ。 1回押すだけで、パソコンを起動したら勝手に動くようになります。黒い画面も出ません。

1
いつでも使えるようにする.bat をダブルクリック
⚙️ いつでも使えるようにする.bat

Windows が「このアプリがデバイスに変更を加えることを許可しますか」と聞いてきます。 「はい」を押してください。ファイアウォールを開けるために必要です。

2
これで終わりです

もう「はじめる.bat」を押す必要はありません。パソコンを起動したら Mr.Drop が動いています。 iPhone から、そのまま送ってください。

やめたいときは scripts フォルダの中で install-windows.ps1 -Uninstall を実行します（保存先の中身はそのままです）。 今どうなっているかは -Status で分かります。

よくある質問

iPhone の Safari で .local の住所が開けません
黒い画面に一緒に出ている http://192.168.… の方を打ってください。こちらは必ず開きます。 .local は Wi-Fi 機器によって通らないことがあります。
どちらの住所でも開けません
まず iPhone と PC が同じ Wi-Fi かを確かめてください（PC が有線でも、同じルーターなら大丈夫です）。 次に、Windows のファイアウォールで「プライベート ネットワーク」を許可したかを確かめてください。 scripts\install-windows.ps1 を実行すると、そこも含めて整えられます。
「WindowsによってPCが保護されました」と出ました
インターネットから落としたファイルに出る警告です。「詳細情報」→「実行」で進めます。 気になるときは、ZIP を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェックを入れてから展開してください。
黒い画面を閉じてしまいました
もう一度「はじめる.bat」を押せば戻ります。送っている途中で閉じた場合、そのファイルは届いていません （中途半端なファイルは残らないようにしてあります）。
同じ名前のファイルを送ったら、上書きされますか
されません。写真.jpg の次は 写真 (2).jpg になります。
iPhone のアプリはありますか
App Store で無料で公開しています（「Mr.Drop」で検索）。 この道具は、アプリを入れたときが本来の形です。写真アプリの共有ボタンからそのまま送れて、 送り先の PC も自動で見つけます。共有ボタンから送れば、アプリを閉じても転送は続きます。
アプリを入れられない iPhone や Android のために、ブラウザだけで送れる画面も用意してあります （Safari で住所を開くだけ。共有ボタン →「ホーム画面に追加」で、次から1タップで開けます）。
Android でも使えますか
同じ Wi-Fi にいれば、Chrome で同じ住所を開くだけで使えます。iPhone 専用ではありません。
Mac でも動きますか
動きます。ただしこの ZIP は Windows 用で、Mac 用の起動役は入っていません。 Mac で使うときは配布元から一式を取得し、bash scripts/install-mac.sh を実行してください （保存先は ~/Downloads/保存先 になります）。

動作環境

Windows 10 / 11 Node.js 18 以降 iPhone（Safari）/ Android（Chrome） 同じ Wi-Fi（LAN）
すべての環境での動作を保証するものではありません。Wi-Fi 機器の設定によっては、 同じネットワークにいる機器どうしの通信が禁止されている場合があり（プライバシーセパレータ等）、 そのときはこの道具は使えません。
