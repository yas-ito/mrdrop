## ① 「PC → iPhone」の節（いちばん大事）

**いま書いてあること**（2026-09-14 にそちらが直した版）は、
「iPhone 側はブラウザで取りに行く」「**iOS アプリには受け取る機能が無い**」。
**この2つ目が嘘になります。**

**こう書き換える:**

```
■ パソコン → iPhone（受け取る）

パソコンの「デスクトップ › Mr.Drop送信箱」フォルダに入れたファイルを、iPhone から受け取れます。

【iPhone アプリで受け取る（おすすめ）】
 1. iPhone で Mr.Drop アプリを開き、下の「受け取る」を押す
 2. 送信箱の中身が一覧で出るので「すべて受け取る」を押す
 3. 写真と動画は「写真」アプリへ、それ以外は「ファイル」アプリ（Mr.Drop › 受信）へ入ります
 ※ iPhone アプリ 1.1.0 以降の機能です（App Store で無料・更新してください）

【ブラウザで受け取る（アプリを入れていないとき）】
 これまでどおり、iPhone の Safari / Chrome で パソコンの住所を開いても受け取れます。

⚠ どちらの方法でも、iPhone に通知は出ません。
　 iPhone から見に行ったときに一覧に出ます
　 （アプリが閉じているあいだ、iOS は Wi-Fi を見張らせてくれないためです）。
```

## ③-2 「アップデートのしかた」の節を新しく足す（本人指示 2026-09-14）

**買った人は「新しい版が出たけど、どうやって入れ替えるの？」で必ず止まります。**
説明書にも同じ節を足しました（`取扱説明書.html` / `取扱説明書-Mac.html` の
「新しい版に入れ替えるとき」）。BOOTH の商品説明にも、短い版を置いてください。

```
■ アップデートのしかた

【パソコン側】入れ直す必要はありません。上書きするだけです。
　設定（保存先・送信箱・パソコンの名前・合言葉）はそのまま引き継がれます。

　Windows
　 1. BOOTH の購入履歴から新しい ZIP をダウンロードする
　 2. ZIP を右クリック →「すべて展開」
　 3. 「はじめる.bat」をダブルクリックする
　 　 前の版は自動で止まり、新しい版に入れ替わってまた常駐します
　 ※ 先に「アンインストール」しないでください。設定まで消えます

　Mac
　 1. BOOTH の購入履歴から新しい ZIP をダウンロードする
　 2. メニューバーの雫 →「Mr.Drop を終了」
　 3. ZIP を展開し、出てきた Mr.Drop を「アプリケーション」へ入れて「置き換える」
　 4. ダブルクリックで開く（「ログイン時に起動」もそのまま引き継がれます）

【iPhone アプリ】App Store から更新します。
　 1. App Store を開き、右上の自分のアイコンを押す
　 2. 下へスクロールし「利用可能なアップデート」の Mr.Drop で「アップデート」を押す
　 3. 出てこないときは、すでに最新です
　 ※ iPhone の「設定 → App Store → Appのアップデート」を入にしておくと自動で新しくなります
```

🔵 **この節は 1.1.0 と関係なく、いま入れても嘘になりません。**
①②（受け取り機能の話）は公開後ですが、**これだけは先に入れて構いません。**
