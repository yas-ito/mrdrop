macOS 13 以降 / Apple シリコン・Intel 両対応 / インターネットを通りません
まず、これだけ
  1. ZIP をダブルクリックして展開し、出てきた Mr.Drop を「アプリケーション」フォルダへ入れる
  2. Mr.Drop をダブルクリック。メニューバー（画面の上）に 雫のアイコン が出ます
  3. 「ローカルネットワーク」の許可を聞かれたら 「許可」
  4. iPhone の Mr.Drop アプリ（または Safari）から送る。選んだ瞬間に Mac へ届きます

このツールについて

Mr.Drop は、iPhone から、同じ Wi-Fi につながっている Mac へファイルを送る道具です。 AirDrop と同じ使い心地を、Windows と Mac の両方で同じように使えるようにしたものです。

  • インターネットを通りません。端末どうしが直接やりとりします。写真がどこかのサーバーに残ることはありません
  • 元のまま届きます。HEIC が JPEG に変換されたり、動画が小さくされたりしません（iPhone 側で「PC で扱いやすい形式」を選んだときだけ、JPEG / MP4 にして送ります）
  • メニューバーに常駐するだけ。Dock にも出ませんし、ウインドウもありません
  • Mac → iPhone もできます。Mac の「送信箱」に入れたものを、iPhone の Safari から受け取れます
追加のソフトは何も要りません。必要なものは全部 Mr.Drop の中に入っています。

始める

1
Mr.Drop を「アプリケーション」に入れてダブルクリック

初めて開くときは「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか？」と聞かれます。 「開く」を押してください。Apple の公証を通してあるので、「開発元を確認できません」とは言われません。

2
「ローカルネットワーク上のデバイスの検索と接続を許可しますか」と聞かれたら

「許可」を押してください。ここで断ると、iPhone から Mac が見えません。 あとから直すには、システム設定 →「プライバシーとセキュリティ」→「ローカルネットワーク」で Mr.Drop をオンにします。

3
メニューバーの雫を押す

「待っています」と出ていれば準備完了です。その下に、iPhone の Safari で開ける住所が並びます （押すとコピーされます）。iPhone アプリを使うなら、住所は要りません。アプリが勝手に Mac を見つけます。

送る・受け取る

iPhone → Mac（送る）

iPhone アプリなら、写真アプリの共有ボタンに「Mr.Drop」が並びます。AirDrop と同じ操作です。 アプリを開いて「写真・動画を送る」からも送れます。

Safari なら、メニューに出ている住所を開いて「写真・動画を選ぶ」を押します。

⚠ 送信ボタンはありません

選んだ瞬間に送り始めます。「送信」ボタンを探す必要はありません。 棒グラフが伸びて「送りました」に変われば完了です。何度も選び直すと、同じ写真が何枚も届きます。

届いたものは Mac の受信箱に入ります。初期設定では「ダウンロード」の中の「受信箱」フォルダです。 メニューの「受信箱を開く」で開けます。

Mac → iPhone（受け取る）

Mac の送信箱フォルダ（「ダウンロード」の中の「送信箱」）に入れたファイルが、iPhone の Safari の画面の下の方に一覧で出ます。 「受け取る」を押すと iPhone に落ちます。

大きい動画を送るとき

  • 数GB の動画でも送れます。速さは Wi-Fi 次第です（有線の Mac 相手なら、実測で毎秒 60〜80MB 出ています）
  • 途中で切れたファイルは受信箱に出しません。中途半端なファイルが紛れ込まないようにしてあります。切れたら、もう一度送ってください
  • iPhone アプリなら、送っている間に画面を閉じても続きます（共有シートから送ったとき）

安全の話（読んでください）

⚠ 同じ Wi-Fi にいる人は、誰でも使えます

初期設定では、同じネットワークの中にいる人なら誰でもあなたの Mac へファイルを送れ、 送信箱の中身を見て受け取れます。家の Wi-Fi なら問題になりませんが、 職場・学校・宿・カフェなど、知らない人が同じ Wi-Fi にいる場所では使わないでください。

  • インターネット側からは使えません。同じネットワークの中からしか受け付けない作りになっています
  • 受信箱と送信箱の外には、絶対に書き込みません。ファイル名に細工がされていても、名前だけを取り出して受信箱に入れます

合言葉をつける

どうしても人の多いネットワークで使うなら、合言葉を設定してください。

  1. メニューの「合言葉を決める…」を押して、好きな言葉を入れます
  2. iPhone アプリなら「合言葉」の欄に同じ言葉を入れます
  3. Safari からは http://…:48630/?t=すきな合言葉 で開きます

よくある質問

iPhone から Mac が見つかりません
上から順に確かめてください。
① メニューバーに雫が出ていて「待っています」になっているか
② iPhone と Mac が同じ Wi-Fi か（Mac が有線でも、同じルータなら大丈夫です）
③ Mac の「システム設定 → プライバシーとセキュリティ → ローカルネットワーク」で Mr.Drop がオンか
④ iPhone の「設定 → プライバシーとセキュリティ → ローカルネットワーク」で Mr.Drop がオンか
それでも駄目なら、iPhone アプリの「住所を手で入れる…」に、メニューに出ている http://192.168.…:48630 を入れてください。 宿やカフェの Wi-Fi は端末どうしの通信を止めていることがあり、その場合は使えません。
「番号が塞がっています」と出ます
Mr.Drop が二重に動いているか、別のソフトが 48630 番を使っています。一度「Mr.Drop を終了」してから開き直してください。
iPhone アプリはありますか
App Store で無料で公開する準備をしています（Mr.Drop で検索）。公開までは、Safari で住所を開けば同じことができます。 共有ボタン →「ホーム画面に追加」しておくと、次からアプリのように開けます。
「開発元を確認できないため開けません」と出ます
この版では出ないはずです。出た場合は、ZIP を展開し直して、Mr.Drop を右クリック →「開く」を試してください。それでも出るときはご連絡ください。
受信箱にファイルが出てきません
iPhone 側で「送りました」になっているか確かめてください。途中で切れたものは受信箱に出さない作りです。 メニューの「記録を開く」で、届いたかどうかが分かります。
終了するには
メニューバーの雫 →「Mr.Drop を終了」。受け取りも止まります。
Windows でも使えますか
Windows 版があります（別売）。iPhone アプリは同じものが両方に送れます。
アンインストールするには
「Mr.Drop を終了」してから、アプリケーションフォルダの Mr.Drop をゴミ箱へ。設定は ~/Library/Application Support/Mr.Drop、記録は ~/Library/Logs/MrDrop に残るので、要らなければ消してください。 受信箱の中身は消えません。
