# 使い方編 — 音声とテロップの作り方

台本（`../台本-使い方編.md`）から、**貼り付けるだけの2つのテキスト**を作ってあります。
**台本を直したら、まず `node build-text.js` を走らせ直してください。**

```bash
node ~/開発/Mr.Drop/紹介動画/音声-使い方編/build-text.js
```

| 作られる物 | どこへ貼るか |
|---|---|
| `minimax-貼る.txt` | MiniMax Audio（Web）の入力欄 |
| `台本を当てる-貼る.txt` | 一撃極の字幕編集タブ →「台本を当てる…」 |

読ませる字と、画に出す字は**別物**です。MiniMax にはかな書き（「アイフォン」）、
テロップはふつうの表記（「iPhone」）。**「台本を当てる」がこの違いを吸収します。**

---

## ① 音声を作る（MiniMax Audio）

1. `minimax-貼る.txt` を**全部**コピー（場面の切れ目に `<#2#>`＝2秒のポーズが入っています）
2. <https://www.minimax.io/audio/text-to-speech> を開く（Chrome はログイン済み・声は **yas**）
3. 貼って生成 → 再生バー右端の **⬇ → WAV** で落とす

🔴 **1回で全部作ること。**場面ごとに分けて作ると、声の調子がそろいません。
クレジットは読む字の数だけ（**この台本は約1,400字＝1,400クレジット**）。

## ② 場面ごとに切り分ける

```bash
bash ~/開発/Mr.Drop/紹介動画/音声-使い方編/split.sh ~/Downloads/<落とした>.wav
```

`~/Movies/編集/Pr/Mr.Drop紹介動画アップデート版/音声/S1.wav … S6.wav` ができます。
**MiniMax の出力は小さい（−29 LUFS）ので、−14 LUFS まで持ち上げてあります。**

切れ目が5か所ちょうど見つからないときは、**何もせずに止まって理由を出します**
（半端なファイルを置いていきません）。

## ③ Premiere に並べて、テロップを作る

1. S1〜S6 を順に並べる（図と録画はこの音に合わせて置く）
2. 一撃極で**文字起こし**する
3. 🔴 **「文字起こし」タブ →「1行の最大文字数」を 18** にする（既定は 20 なので**変えること**）
4. **字幕編集タブ →「台本を当てる…」**を開く
5. `台本を当てる-貼る.txt` を**全部**貼る
6. **「台本の改行でテロップを区切る」をオン**（1行＝テロップ1枚。この時だけ時刻が変わります）
7. 「台本を当てる」を押す

whisper からは**時刻だけ**を取り、**文字は台本のもの**に差し替わります。
`Mr.Drop`・`iPhone`・`Wi-Fi` の表記ゆれと誤字は、これで一度に消えます。

🔵 **各行に札が付きます** ── `台本`＝一致／`要確認`＝当てたが音と10字以上ちがう／
`台本になし`＝台本に無い発話。**「要確認だけ表示」**で確かめる所だけに絞れます。

---

## 直すときの決まり

🔴 **`minimax-貼る.txt` と `台本を当てる-貼る.txt` を直接書き換えないこと。**
次に `build-text.js` を走らせた瞬間に消えます。**直すのは台本の1か所だけ**です。

テロップの割り方（18字・句読点なし・短い断片を作らない）は `build-text.js` の中にあります。
