# iPhone 側の録画 — お願いしたいこと

台本は [`台本.md`](台本.md)。**この指示だけ見て撮れる**ように書いてあります。
全部で **11 カット・撮影は 15 分ほど**です。難しいものはありません。

---

## 🔴 まず、撮り方を2つから選んでください

| | やり方 | 良い点 | 悪い点 |
|---|---|---|---|
| **おすすめ** | **Mac に iPhone をケーブルでつなぎ、QuickTime Player の「新規ムービー収録」でカメラを iPhone にする** | **時計が赤くならない**・通知が映らない・撮れているか大画面で見える・60fps | Mac に持っていく手間 |
| 手軽 | iPhone だけで「画面収録」 | すぐ撮れる | **収録中は時計が赤く光る**・通知が映り込む事故 |

**Mac があるので、できれば上をおすすめします。**画面の上の時計が赤いと、
素人録画に見えてしまいます。上でいきますか、下でいきますか——**どちらでも構いません。
決めたら教えてください。**（下でも、下の準備をすれば十分きれいに撮れます）

---

## 撮る前の準備（どちらのやり方でも）

- [ ] 🔴 **集中モードを「おやすみモード」に**（通知バナーが映り込むと全カット撮り直しになります）
- [ ] 🔴 **写真アプリに「撮影用のアルバム」を1つ作る。**送るのは**風景や物**にしてください。
      人の顔・書類・住所・お子さんの写真は、拡大されて世界中に出ます
- [ ] **ファイル名も映ります。**`IMG_0004` のような既定の名前のままが安全です
- [ ] 画面の明るさを上げる（自動明るさは切っておくと、途中でちらつきません）
- [ ] バッテリーは 50% 以上。充電ケーブルは挿さない（稲妻マークが出ないように）
- [ ] **画面収録のマイクは切る**（音は使いません。生活音が入るだけです）
- [ ] iPhone と PC を**同じ Wi-Fi** に。PC 側の Mr.Drop は私が動かしておきます
- [ ] 大きい動画のカット（E）用に、**1GB 以上の動画**を1本、写真アプリに用意

---

## 撮り方の決まり（これだけ守れば、あとは自由）

1. 🔴 **1カットずつ、別々に撮る。**通しで撮らないでください。撮り直しが楽になります
2. 🔴 **前後に「2秒じっとする」**を必ず入れる。押してすぐ止める・録ってすぐ押す、をやると
   編集で切るところが無くなります
3. **ゆっくり。**タップの前に 0.5 秒止まる。スクロールは1回だけ、ゆっくり
4. **失敗しても止めない。**そのまま2秒待って、もう一度やってください。あとで良い方を使います
5. **縦のまま撮る。**横にしないでください。**横動画の中に、縦のまま置きます**
6. 同じカットを**2回ずつ**撮っておくと安心です

## 撮ってほしいカット（A〜J）

**★** が付いているものが特に大事です。時間が無ければ ★ だけでも形になります。

> 🔴 **主役は B（アプリから送る）です。**台本を「アプリが主・共有ボタンが従」に直したので、
> 先に B を撮ってください。C はそのあとの「こういう送り方もできます」です。

| | 中身 | 尺 | 注意 |
|---|---|---|---|
| **A** | ホーム画面 → **Mr.Drop のアプリ**を開く | 5秒 | ホーム画面は1ページ目。並びが見えるので、見られて困るアプリは移動を |
| **B ★★** | アプリの画面 → **PC が自動で出てくる** → 「**写真・動画を送る**」→ 写真を選ぶ → 送る → **「送りました」** | 20秒 | **この動画の看板**。「同じ Wi-Fi の PC を探しています…」から**PC 名が出る瞬間**を必ず入れて、そこで1秒止まる |
| **C ★** | 写真アプリ → 写真を1枚 → **共有ボタン** → 共有シートの **Mr.Drop** → 送る | 15秒 | 共有シートに Mr.Drop が並んでいる所で1秒止まる |
| **D** | 写真を5枚＋動画1本、まとめて選んで送る | 12秒 | まとめて送れることが見せ場 |
| **E ★** | **1GB 以上の動画**を送る → 進み具合 | 20秒 | 進み具合のバーが動いている所が要ります。**途中で止めず、最後まで** |
| **F ★** | 「送る形式」を開く → **初期設定で「入」になっている**所 → 一度切り替えて戻す | 10秒 | S4 で使います。**入になっている状態**を必ず映してください |
| **G** | ファイルアプリから「ファイルを送る」で PDF を1つ送る | 10秒 | 写真以外も送れることの証明 |
| **H** | **PC → iPhone**：送信箱に置いたものを iPhone の画面から受け取る | 12秒 | 私が先に送信箱へ PDF を置いておきます。**合図してください** |
| **I** | Safari で `http://<PC名>.local:48630` を開いて送る（アプリ無しの道） | 12秒 | 補足用。無くても成立します |
| **J ★** | App Store の Mr.Drop のページ（「入手」が見える所） | 6秒 | 締めで使います |

## 🔴 B・C・E は「同時録画」でお願いします

**iPhone で送る瞬間と、PC に着弾する瞬間を、実時間で揃えたい**からです。
別々に撮って並べると、どうしても嘘っぽくなります。

**やり方はこれだけ：**

1. あなた「**録画はじめる**」と私に言う
2. 私が PC 側の録画を開始して「**どうぞ**」と返す
3. あなたが iPhone の録画を始めて、**3秒待ってから**送る操作をする
4. 送り終わって2秒待ってから、iPhone の録画を止める
5. あなた「**止めた**」と私に言う → 私も PC 側を止める

**3 の「3秒待つ」が合わせ目になります。**ここだけ守っていただければ、あとは私が揃えます。

## 撮れたら、私に渡してください

**Mr.Drop で送ってください。**（この動画の素材を Mr.Drop で運ぶ、というのが一番早いので）

- 送り先の受信先は、いまは `C:\Users\yasma\Downloads` です
- 送っていただいたら「**送った**」と言ってください。こちらで拾って
  `_build\紹介動画\iPhone\` へ仕分けます
- 🔴 **画面収録は「動画」として写真アプリに入ります。**カット記号（A・B・C…）が
  分からなくなるので、**撮った順に送る**か、**1本送るごとに記号を言う**かのどちらかで

QuickTime（Mac）で撮った場合は、Google ドライブの `伝達専用` へ置いていただければ拾います。

## こちらでやること（あなたは何もしなくて大丈夫です）

- PC 側の画面録画（着弾・タスクバー・導入・アンインストール・送信箱）
- MiniMax でナレーションを作る（台本の「読み上げ用テキスト」をそのまま）
- Premiere のプロジェクトを組んで、並べて、テロップまで入れる

**BGM だけ、最後にあなたが乗せてください。**着弾の瞬間（0:38 あたり）に
効果音が入る想定で、前後に余白を残してあります。
