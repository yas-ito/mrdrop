## プロモーション用テキスト（170 文字まで・審査なしで変えられる）
写真も動画も、撮ったままの画質で Windows / Mac へ。インターネットを通らず、同じ Wi-Fi の中で直接届きます。

## 説明（4000 文字まで）
Mr.Drop は、iPhone の写真・動画・ファイルを、同じ Wi-Fi につながったパソコンへ直接送るアプリです。
Windows には AirDrop がありません。Mr.Drop は、その代わりになるものとして作りました。

■ 使い方
・写真アプリの共有ボタンから「Mr.Drop」を選ぶだけ。AirDrop と同じ操作です
・アプリを開いて「写真・動画を送る」からも送れます
・送り先のパソコンは自動で見つかります。IP アドレスを打つ必要はありません

■ 特長
・インターネットを通りません。端末どうしが直接やりとりします。写真がどこかのサーバーに残ることはありません
・元のまま届きます。HEIC が勝手に JPEG に変換されたり、動画が小さくされたりしません
・「PC で扱いやすい形式にする」をオンにすると、HEIC は JPEG、MOV は MP4 にして送ります（動画は容器を替えるだけで画質は変わりません）
・数 GB の動画も送れます。共有シートから送れば、アプリを閉じても転送は続きます
・アカウント登録なし。データ収集なし

■ 必要なもの
このアプリは「送る側」です。受け取る側のパソコン（Windows / Mac）で、受信用の Mr.Drop が動いている必要があります。
iPhone とパソコンが同じ Wi-Fi（同じルータ）につながっている必要があります。

■ 見つからないときは
・パソコン側で Mr.Drop が動いているか、同じ Wi-Fi かを確かめてください
・iPhone の「設定 › プライバシーとセキュリティ › ローカルネットワーク」で Mr.Drop を許可してください
・それでも見つからないときは、パソコンの画面に出ている住所を「住所を手で入れる」に入力できます
